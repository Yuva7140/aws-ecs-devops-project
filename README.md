# AWS ECS DevOps Project

## Overview

This project demonstrates deploying a Python Flask application to Amazon ECS using Docker, Amazon ECR, Application Load Balancer, and GitHub Actions.

## Technologies

- AWS ECS (EC2 Launch Type)
- Amazon ECR
- Application Load Balancer
- Docker
- Python Flask
- GitHub Actions
- CloudWatch Logs

## Architecture

GitHub → GitHub Actions → Amazon ECR → Amazon ECS → ALB
